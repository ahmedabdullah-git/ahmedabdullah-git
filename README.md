## 👋 Hi, I'm Ahmed Abdullah — Full Stack AI Engineer & Software Developer

I'm a **Full Stack AI Engineer** and **Software Developer** with end-to-end expertise in building intelligent, production-ready applications. I specialize in **Generative AI**, **Large Language Models (LLMs)**, **Retrieval Augmented Generation (RAG)**, and **AI Agent** systems using **LangChain** and **LangGraph**.

On the backend, I design scalable **REST APIs** and services with **Python** (**FastAPI**, **Flask**), **Node.js / Express**, and **.NET / C#**. On the frontend, I build fast, responsive interfaces with **React**, **Next.js**, **Vue.js**, and **TypeScript**. For data, I work with **PostgreSQL**, **SQL**, **NoSQL** (MongoDB), **Neo4j** graph databases, and vector stores like **Pinecone**, **ChromaDB**, and **FAISS**.

Whether it's an **AI-powered chatbot**, an **autonomous AI agent**, a **RAG pipeline** over enterprise knowledge bases, or a **full-stack web application** — I build it end to end.
